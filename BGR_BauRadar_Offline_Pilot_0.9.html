Verantwortung aktuelle Phasenoch offenWird im Phasenplan festgelegt.

Für jede Phase werden Zeitraum, Status und Verantwortung separat festgelegt. Zusätzlich wird geklärt, ob Ressourcenbedarf erfasst wird oder bewusst kein zusätzlicher Bedarf besteht. Erst ein Start und ein Ende machen aus einer offenen Phase eine zeitliche Planung.

Diese Rollen gelten für das ganze Projekt. Die operative Verantwortung wird dagegen für jede Phase im Phasenplan festgelegt. Die Bauherrenbegleitung wird separat mandatiert und ist spätestens ab Machbarkeitsstudie dabei.

Restbedarf dieses ProjektsJe Person oder Firma und Projektphase wird genau ein Wert erfasst.

Bei zukünftigen Phasen entspricht der Wert dem gesamten erwarteten Bedarf. Bei laufenden Phasen wird nur eingetragen, was ab heute noch benötigt wird. Das BauRadar verteilt nichts auf einzelne Monate.

Finanzen sind kein Pflichtfeld. Ein Projekt oder eine Phase kann auch ohne erfasste Finanzen freigegeben werden. Der BauRadar zeigt dann einen Hinweis. Wenn Finanzen erfasst werden, erfolgt dies projektweit pro Jahr.
