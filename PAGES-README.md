# BGR BauRadar – GitHub Pages Pilot 0.9

Diese Veröffentlichungsfassung enthält den freigegebenen BGR-Mutterstand vom 14.08.2026 mit 36 Projekten und die aktuelle Pilot-Fachlogik. Wer die Seite aufruft, sieht diesen Startstand sofort. Die Teständerungen werden ausschliesslich im jeweiligen Browser gespeichert und nicht mit anderen Personen synchronisiert.

## GitHub Pages

Der Repo-Administrator aktiviert GitHub Pages in https://github.com/FabriInno28/BGR_Bau_test/settings/pages mit „Deploy from a branch“ → `gh-pages` → `/(root)`. Erwartete Pages-Adresse: https://fabriinno28.github.io/BGR_Bau_test/

Falls GitHub die Pages-Aktivierung für dieses private Repository im aktuellen Kontoplan nicht anbietet, kann der Eigentümer die Repository-Sichtbarkeit unter Settings → General → Danger Zone auf öffentlich ändern. Dabei wird **das gesamte Repository inklusive seiner übrigen Branches und Historie** öffentlich. Deshalb nur nach bewusster Freigabe (Stand und Inhalt prüfen).

## Testhinweis

Die Testenden können unmittelbar beginnen. Jede Person hat einen lokalen Arbeitsstand, keine gemeinsame Datenbank. Bei Wechsel von Browser/Endgerät ist der bisherige Stand nicht automatisch vorhanden. JSON-Vollsicherung regelmässig über die Übergabe-Funktion exportieren und bei Bedarf auf einem anderen Gerät wieder einlesen.

Die Anwendung ist ein Pilot und dient nicht als verbindliche Entscheidungsgrundlage.
